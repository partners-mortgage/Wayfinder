PARTNERS ACADEMY · PHASE 1

Migration console

Moves published courses from the old Academy project into the Academy database, applying the locked decisions: published only, chapters flattened, guide lessons dropped, progress abandoned. Nothing is written until you read the inventory and press the write button. Read the inventory carefully, because the dropped lessons are content your team will have to re-author.

1Connect both projects

Two separate Firebase projects means two separate sign-ins, even with the same email. Source is partners-playbook, target is wayfinder-1b0a4. You need admin on both.
not connected
Nothing is stored. The password is used for two sign-in calls and never written anywhere. If the two projects use different passwords, connect the source first, then use the target field that appears.

2Inventory, before anything is written

Every published course, and exactly what it loses. A course marked lesson loss will arrive in the new Academy with fewer lessons than it has today.

3Write into the Academy

Dry run first. It performs every read and builds every document, then reports what it would write without writing it. Only press the real write once the dry run looks right.
not run
Writes use the source course id as the target document id, so running this twice overwrites rather than duplicating. That is deliberate: a rerun after a fix is safe.
